# **App Name**: AlphaEdge Academy

## Core Features:

- Educational Content Pages: Dedicated pages for Forex, Commodities, Indices, Stocks, Futures, Options and Crypto, detailing trading concepts.
- About Me Section: Highlight your prop firm experience and trading philosophy to build trust.
- Market Insights Blog: A regularly updated blog on technical trading concepts like price action, market structure and institutional concepts.
- Free Resources Library: Offer downloadable guides, charts, and other educational content.
- Market Commentary Section: Provide high-level, educational analysis of market trends. All copy will run through a moderation tool that makes suggestions to the writing to ensure it doesn't suggest trades, but provides analysis using different sentence construction
- Clear Disclaimer: A static disclaimer page clearly states educational purposes, not financial advice.
- Contact Section: Allow user to contact you for feedback or to ask any questions they may have about the material

## Style Guidelines:

- Primary color: Deep navy blue (#1A237E) to evoke a sense of professionalism and credibility, avoiding common 'money' cliches.
- Background color: Dark gray (#212121) for a modern trading-style theme, and comfortable contrast.
- Accent color: Muted gold (#BDBDBD) analogous to navy but far lighter, for highlights and key interactive elements.
- Headline font: 'Space Grotesk' sans-serif for headlines to give a modern, technical feel.
- Body font: 'Inter' sans-serif to ensure readability and a clean interface.
- Simple, geometric icons representing different markets (Forex, Commodities, etc.).
- Clean, grid-based layout to provide structure, technical diagrams, and clear data visualization.
